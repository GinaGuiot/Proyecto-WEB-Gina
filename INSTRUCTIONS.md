# INSTRUCTIONS · CHROMA

## Identidad visual y experiencia por scroll

QUIERO: Una web de CHROMA con una identidad visual reconocible, dos loops de scroll y tres composiciones gráficas conectadas.

SERÁ BUENO SI:
- La tipografía de toda la web es Instrument Serif.
- El fondo es grafito, el texto legible y los acentos cromáticos vivos.
- El logo pequeño, formado por las seis barras de color sin letras, permanece arriba a la izquierda en la cabecera fija.
- El logo grande CHROMA aparece en la portada. Las letras permanecen estáticas sobre una base recta; solo cambia ligeramente la altura de las barras desde arriba.
- El primer loop presenta el logo grande, una introducción general a CHROMA y el botón «Ver mi universo musical».
- El botón lleva al segundo loop.
- Al inicio del segundo loop aparecen las tres composiciones juntas, organizadas en una fila horizontal.
- Al seguir desplazándose, las composiciones se abren una a una a pantalla completa con transiciones interactivas y conectadas entre sí.
- Cuando una composición está desplegada, las otras dos quedan ocultas y no se ven como fondo.
- La composición ocupa el espacio visual completo, sin quedar dentro de un rectángulo enmarcado; el texto explicativo se mantiene separado del lienzo.
- La barra superior sigue fija durante todo el recorrido.
- La experiencia se adapta a móvil, teclado y preferencia de movimiento reducido.

NO SIRVE SI:
- Se mueven las letras o la base del logo durante la animación.
- Las composiciones se superponen o permanecen visibles detrás de la activa.
- El resumen inicial de las tres composiciones se organiza en vertical.
- El scroll no permite avanzar por las visualizaciones.

## 1. Universo de artistas

QUIERO: Una composición de círculos que permita explorar artistas y hábitos de escucha.

SERÁ BUENO SI:
- Cada círculo representa un artista.
- El tamaño corresponde a los minutos escuchados y el color al género musical.
- Al pasar el cursor por cada círculo se muestran artista, género y minutos de escucha.
- La misma información se puede consultar mediante toque en pantallas táctiles.
- Los datos de ejemplo se identifican claramente como provisionales.

NO SIRVE SI:
- Los artistas, géneros o minutos inventados se presentan como datos reales.
- El tamaño y el color no tienen una relación comprensible con los datos.

## 2. Anillos por año — propuesta pendiente de validar

La web muestra anillos concéntricos para explorar cambios a lo largo del tiempo. Antes de aprobar la propuesta, confirmar que la exportación permite calcular los datos por artista y año, el periodo representado y la escala.

## 3. Ritmo semanal — propuesta pendiente de validar

La web muestra una matriz de días y horas con valores ilustrativos. Antes de aprobarla, confirmar que la exportación contiene suficientes fechas y horas, definir qué expresa la intensidad y comprobar que aporta una lectura distinta a las otras composiciones.

Las propuestas 2 y 3 son provisionales. Si los datos no permiten construirlas con rigor, plantear alternativas basadas en campos disponibles.

## Datos y transparencia
- No inventar artistas, géneros, reproducciones, minutos ni patrones.
- No presentar hipótesis como hallazgos antes de comprobarlas.
- Mantener la etiqueta de datos de ejemplo mientras la web use contenido provisional.
- Definir la clasificación de géneros y su paleta después de revisar la exportación.
