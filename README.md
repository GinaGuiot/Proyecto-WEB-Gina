# CHROMA

CHROMA transforma mis hábitos personales de escucha musical en una identidad visual mediante color, formas y datos de Spotify.

## Web y repositorio

- **Web publicada:** [https://ginaguiot.github.io/Proyecto-WEB-Gina/](https://ginaguiot.github.io/Proyecto-WEB-Gina/)
- **Repositorio:** [GinaGuiot/Proyecto-WEB-Gina](https://github.com/GinaGuiot/Proyecto-WEB-Gina)

## Experiencia por scroll

La web tiene dos loops:

1. **Portada:** logo principal CHROMA, introducción breve y botón «Ver mi universo musical».
2. **Universo musical:** al entrar se ven las tres composiciones en una fila horizontal. Al continuar el scroll, se despliegan una por una a pantalla completa, conectadas por transiciones. Cuando una está activa, las otras dos se ocultan. La cabecera fija mantiene el logo pequeño arriba a la izquierda.

## Composiciones

1. **Universo de artistas:** cada círculo representa un artista; el tamaño corresponde a los minutos escuchados y el color al género. Al pasar el cursor o tocarlo se muestran artista, género y minutos.
2. **Anillos por año:** propuesta de anillos concéntricos para explorar cambios a lo largo del tiempo.
3. **Ritmo semanal:** propuesta de matriz que cruza días y horas de escucha.

Las composiciones 2 y 3, así como los valores visibles, son provisionales y deben validarse con la exportación real de Spotify. Los nombres, géneros, minutos y patrones de la versión actual son datos de ejemplo; no representan resultados reales.

## Identidad visual

- Tipografía: **Instrument Serif**.
- Fondo grafito, texto claro y acentos de color vivos.
- El logo grande mantiene las letras estáticas sobre una base fija; las barras solo cambian de altura desde arriba.
- El logo pequeño está formado por las seis barras de color, sin letras.
