# CHROMA

CHROMA convierte hábitos personales de escucha musical en una identidad visual mediante color, formas y visualización de datos de Spotify.

## Experiencia web
La web se organiza en dos zonas de scroll: una portada con el logo principal, una introducción y el botón «Empezar»; y una zona de visualizaciones con tres fichas gráficas.

La primera composición, «Universo de artistas», representa cada artista con un círculo. El tamaño corresponde a los minutos escuchados, el color al género, y al explorar el círculo se muestra el artista, el género y el tiempo de escucha.

## Identidad visual
- Tipografía: Instrument Serif.
- Logo pequeño de barras sin letras en la esquina superior izquierda.
- Logo principal CHROMA en la portada. Las letras quedan estáticas; solo se alarga y acorta suavemente la parte superior de las barras.
- Fondo grafito con acentos cromáticos vivos.

## Composiciones
1. Universo de artistas — definida.
2. Anillos de escucha por año — propuesta pendiente de confirmar con la exportación de Spotify.
3. Ritmo semanal — propuesta pendiente de confirmar que la exportación incluye fecha y hora.

Los datos de muestra no representan todavía una escucha real. No se deben presentar como hallazgos los artistas, géneros, minutos o patrones provisionales.
