# CONTEXT · CHROMA
Última actualización: [dd/mm/aaaa]

## La pregunta
¿Cómo pueden transformarse los hábitos de escucha musical de una persona en una identidad visual mediante el uso del color, las formas y la visualización de datos?.

## Los datos
- Fuente 1: Spotify. Datos personales de escucha obtenidos de mi cuenta de Spotify. Se utilizarán para analizar los artistas, géneros musicales y hábitos de reproducción.
- Datos de escucha: Historial de reproducciones y tiempo dedicado a escuchar cada artista, siempre que esta información esté disponible en los datos exportados.
- Datos musicales: Artistas y géneros musicales asociados a mis escuchas. Se utilizarán para establecer relaciones y construir las composiciones visuales.
- Falta: Concretar el periodo temporal que abarcan los datos, el número de registros disponibles y qué información exacta contiene la exportación de Spotify.
- No tengo: No se deben suponer géneros, artistas, cantidades de reproducciones, minutos de escucha ni tendencias musicales que no estén respaldados por mis datos reales.

## El tono
Personal, colorido y visual.

imagen conceptual:
Mi identidad musical convertida en un universo de colores, formas y relaciones visuales. Cada artista y cada género construyen una parte de ese universo.

## Referentes
- [Referente]: Visualización de datos: Referentes de diseño de información que transforman conjuntos de datos en representaciones gráficas atractivas, comprensibles y con personalidad. 
Arte generativo: Composiciones construidas a partir de reglas, variables y relaciones entre datos. Me interesa la posibilidad de que los propios datos determinen las formas, tamaños y colores.
Identidad cromática: El uso del color como herramienta para clasificar, relacionar y diferenciar géneros musicales.

- [Contrarreferente]: Dashboards estadísticos convencionales, gráficos de Excel o visualizaciones excesivamente técnicas que se limiten a mostrar números sin una intención estética o conceptual.

## Decisiones
- [6/11] El proyecto se llamará CHROMA. Motivo: El nombre conecta directamente los conceptos de color y música.
- [23/10] La fuente principal de información serán mis propios datos de Spotify. Motivo: El proyecto debe representar mis gustos musicales reales y tener un carácter personal.
- [6/11] Los géneros musicales se representarán mediante colores. Motivo: Crear un código cromático que permita identificar y relacionar las diferentes categorías musicales.
- [6/11] Se desarrollarán al menos tres composiciones gráficas diferentes. Motivo: Explorar distintas formas de interpretar y representar los mismos datos musicales.

## Hipótesis (sin comprobar)
- Mis gustos musicales pueden representarse mediante una identidad cromática propia.
- Algunos géneros musicales tendrán una presencia mucho mayor que otros dentro de mis hábitos de escucha.
- La relación entre artistas y géneros puede generar agrupaciones visuales y patrones que no son evidentes al consultar únicamente las estadísticas de Spotify.
- Las diferentes composiciones gráficas permitirán descubrir distintas perspectivas de una misma identidad musical.

## Descartado
- [17/11] Limitar el proyecto a mostrar estadísticas convencionales de Spotify: el objetivo es transformar los datos en composiciones gráficas con valor estético y conceptual, no hacer únicamente un resumen de actividad musical.
